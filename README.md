# EduChain_Grupo_301Distrital
Prototipo funcional de blockchain en Python para asegurar la emision de calificaciones academicas. Implementa SHA-256, arbol de Merkle, firmas digitales ECDSA y Proof of Work. Un Smart Contract restringe la emision de notas a docentes autorizados criptograficamente. Proyecto final - Criptologia, Universidad Distrital FJC.
